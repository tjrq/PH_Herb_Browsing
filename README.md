This folder contains data and R code for data chapter 1 of Timothy Quimpo's thesis and has been published in Marine Environmental Research (https://doi.org/10.1016/j.marenvres.2025.107539). 

Data herein examined changes in the species richness, abundance and bite rates of browsing herbivore fishes and how this varied across a depth range of 1 to 60m in the fished coral reefs of the Bolinao-Anda Reef Complex, Philippines.
