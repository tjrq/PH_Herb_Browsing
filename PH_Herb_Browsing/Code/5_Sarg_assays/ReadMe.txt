Model fits are in the quarto file labelled "sarg_assays_fit". This quarto document has the code for all the analyses conducted on changes in Sargassum mass with depth. The quarto document labelled "sarg_assays_results_plots" contains code on the interpretation and figure generation using the models from the "sarg_assays_fit" file.
