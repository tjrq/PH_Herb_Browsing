CSV files that contained data for each response variable investigated in Chapter 4. 

Specifically, the following response variables are contained in each CSV file:

"abundance_MaxN" - contains data on the MaxN abundance of herbivorous fishes across depth
"bites" - contains data on the number of bites of herbivorous fishes across depth
"macroalgae_functional_group - contains data on the percentage cover of each macroalgae functional group with depth
"major_benthic_cover" - contains data on the percentage cover of benthic categories with depth
"sarg_assays" - contains data on the Sargassum assay mass loss with depth
"total_length_cm - contains data on the estimated body size of browsing fish recorded feeding on the Sargassum assays
